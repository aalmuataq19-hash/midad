حلّل مجلد القضية `$1` بمحرك مِداد، وأنت نفسك النموذج — لا تستدعِ أي API خارجيًا ولا تستعمل مفتاح المستخدم.

## القواعد الملزمة — اقرأها قبل أن تبدأ

هذه قواعد مشروع مِداد، ومخالفتها تُفسد المخرَج ولو كان JSON صالحًا:

1. **لا تذكر ما ليس في المستندات نصًا.** لا تخترع، ولا تكمل من معرفتك، ولا تفترض.
2. **لا تكتب نتيجة قضائية ولا ترجيحًا ولا توصية بالحكم ولا تقييمًا لقوة دليل.**
3. **الألفاظ المحظورة:** «يثبت»، «ثابت»، «ثبت»، «متفق عليه». بدلها: «ورد في المستند»، «ادعى الطرف»، «نازع الطرف»، «لم يظهر في الملف نزاع صريح».
4. **كل عنصر يحمل مصدره** في `src`: اسم المستند كما هو في `doc`، ورقم الصفحة في `page` (وملفات Word بلا ترقيم صفحات فاجعله `0`)، ومقتبس حرفيًا قصيرًا في `quote` لا يتجاوز ٢٥ كلمة.
5. **حقول القاضي لا تُملأ**: `laws` تبقى `[]` دائمًا في هذا الأمر، لأن النصوص النظامية لا تدخل التحليل إلا من مكتبة القاضي داخل الموقع.
6. **عمود الغرض في الأدلة يبدأ حرفيًا** بعبارة «يراد به بحسب المذكرة».
7. **أجب بـ JSON فقط** بلا نص قبله ولا بعده ولا أسوار markdown.

## الخطوات

نفّذ المراحل الست بالترتيب. لكل مرحلة `<م>` من: `overview` ثم `facts` ثم `reqdef` ثم `evidence` ثم `issues` ثم `review`:

1. اطبع توجيه المرحلة:
   ```
   node tools/midad-analyze.js prompt "$1" <م> "$1/.midad/partial.json"
   ```
   المخرَج يحوي نص النظام ومستندات القضية وتوجيه المرحلة. **اتبعه حرفيًا.**

2. إن ذكر المخرَج ملفات تحتاج قراءتها بأداة `Read` (PDF أو صور)، فاقرأها ثم أدخل محتواها في اعتبارك.

3. أنتج JSON المرحلة بالمخطط المطلوب في التوجيه بالضبط، واكتبه في `$1/.midad/<م>.json`.

4. بعد مرحلة `overview` مباشرة، انسخ ملفها إلى `$1/.midad/partial.json` لتصل المسائل إلى مرحلتَي `evidence` و`issues` (فهما تحتاجان قائمة المسائل).

5. بعد المراحل الست:
   ```
   node tools/midad-analyze.js merge "$1"
   ```
   يكتب `$1/analysis.json` بالبنية نفسها التي يخزنها التطبيق، ويفحصها.

   `merge` يضمّن كذلك **نصوص المستندات** في حقل `docs`، فيعمل «اسأل ملف القضية» وعارض
   المستندات بعد الاستيراد بلا رفع ملفات جديدة. سمِّ كل مستند بالاسم نفسه الوارد في
   `src.doc` حتى يفتح العارض المصدر الصحيح:
   ```
   node tools/midad-analyze.js merge "$1" --docs='محضر.txt:محضر الجلسات,لائحة.txt:صحيفة الدعوى'
   ```
   وبلا `--docs` تُضمَّن كل المستندات النصية باسم ملفها كاملًا. و`--no-docs` يمنع التضمين.

6. **إن ظهرت مشكلات في الفحص فأصلحها** في ملف المرحلة المعنية ثم أعد `merge`. لا تسلّم مخرَجًا فيه لفظ محظور أو حقل ناقص.

## في آخر عملك

اذكر للمستخدم بالعربية: عدد المسائل والوقائع والطلبات والدفوع والمستندات والتعارضات وما يحتاج إلى تحقق، ونتيجة الفحص، وأن الملف جاهز للاستيراد من زر **«استيراد تحليل»** في الموقع.

لا تدفع شيئًا إلى git إلا إن طلب المستخدم.
